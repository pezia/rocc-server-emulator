01 / The machine

ROCC Classic systems

ROCC's Classic systems were business minicomputers: one computer, multiple operators, a desk full of terminals. Descended from the 16-bit Data General Nova architecture, they handled data entry and business processing.

Their software evolved from releases known as “Loads” into the Workstation Management System (WMS). The 1986–87 Classic range included the 2825 and 2835 in the compact “Miniboy” cabinet.

This project provisionally identifies its target as the ROCC 2800 Classic family. The exact model and processor revision remain unresolved.

02 / The emulator

What the emulator models

The emulator implements a CPU, banked memory, disk controller, interrupts, and a 24 × 80 terminal. Hardware behavior is inferred and remains incomplete. Guest time is instruction-based, not cycle-accurate.

03 / Build and run

Running the emulator

Requires Rust 1.87 or later, a C linker, and a compatible disk image. The repository includes tests that run without an external image.

Full setup & keyboard guide ↗︎
● ● ● terminal / quick start
# Build the emulator
cargo build --release --locked

# Boot your disk image
./target/release/rocc-emulator boot \
  /path/to/disk.img --interactive

Use a POSIX terminal of at least 80 × 24. Disk images stay read-only; guest writes persist in a separate, writable .overlay. Operating systems and disk images are not included.

Tests and current status

The CLI tests use synthetic disk images. The CPU regression compares 8,262 generated instruction cases against frozen reference results. These checks exercise the implementation; they do not establish compatibility with a complete historical operating system.

cargo test --locked
cargo build --release --locked
python3 tests/cli.py
python3 tests/regression.py --cpu
