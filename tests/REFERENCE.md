# CPU reference provenance

`cpu-reference.json.gz` contains 8,262 frozen synthetic cases. Its metadata records
seed 1380926275 and the description “Synthetic instruction cases with frozen
reference results”. The original generator and oracle are not present. Their
independence and hardware fidelity cannot be established from this repository.
The decompressed SHA-256 remains
`f0e281511050716f1ea3f8b53f321b3bd896f7a209b264427d5a7df68651ae07`.
Do not silently regenerate or replace this baseline.

`generated-reference.json` is a separate corpus generated by
`generate_reference.py` using seed 1380926275 and reference-model version 1.
`reference_model.py` independently evaluates the documented base CPU semantics
using sparse memory, integer arithmetic, and bit-list carry rotations. It never
imports or invokes the Rust implementation. Hand-calculated checks live in
`reference_tests.py`. The generated cases include ALU edge combinations,
addressing displacements, both address widths, and 64 multi-instruction programs.
This model does not claim vendor or physical-machine authority and implements no
peripheral controllers or recovered extensions. Rust integration programs cover
controllers separately with explicitly asserted state transitions.

Regenerate and validate from the repository root:

```sh
python3 tests/reference_tests.py
python3 tests/generate_reference.py
python3 tests/generate_reference.py --check
cargo build --release --locked
python3 tests/regression.py --cpu
```

The check mode is read-only and rejects any byte difference. Generated JSON uses
sorted keys and fixed indentation; timestamps are excluded. Changes to the new
model require review of its version, hand examples, and resulting corpus diff.
